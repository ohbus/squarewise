## Objective

Make CI reject known architectural boundary violations, uncentralized
dependency versions, and tracked secret material while retaining a dependency-
light local execution path.

## Acceptance criteria

- Architecture validation rejects cross-service application imports and known
  forbidden infrastructure-to-domain directions.
- SBOM baseline validation confirms the centralized version catalog exists and
  build scripts do not introduce dependency versions outside it.
- Security hygiene remains an executable gate.
- Pull-request and main CI invoke all three checks.
