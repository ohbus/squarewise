# PR-35: Actuator exposure hardening

- Phase: production_hardening
- Owner role: coordinator
- Dependencies: PR-25, OPS-01
- Owned paths: service security chains/configuration, focused tests, and this task detail

## Objective

Prevent unauthenticated access to actuator information and metrics while
keeping health/readiness probes available to orchestrators.

## Acceptance criteria

- Only `/actuator/health/**` is unauthenticated in deployed security chains.
- `/actuator/info`, `/actuator/metrics`, and `/actuator/prometheus` require
  authentication.
- Existing readiness/liveness health checks continue to work.
- Security tests cover public health and protected diagnostic endpoints.
