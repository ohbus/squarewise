- Phase: production_hardening
- Owner role: coordinator
- Dependencies: PR-17, PR-31

## Objective

Give durable expense idempotency claims an explicit retention window and
bounded cleanup so replay storage cannot grow without limit.

## Acceptance criteria

- Idempotency records are retained for a configured replay window.
- Expired claims are deleted in bounded scheduled batches.
- Cleanup does not affect claims inside the replay window.
- Retention and cleanup behavior have focused tests and operational defaults.

## Current increment

Added a 24-hour default replay retention window and a scheduled cleanup worker
that deletes at most 500 expired claims per run. The retention and bounded
deletion behavior have focused tests.
