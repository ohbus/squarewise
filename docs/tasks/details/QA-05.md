# QA-05: Add public-interface edge-case acceptance journeys

Extend authenticated acceptance coverage for rename rollback, concurrent rename,
member authorization, BFF fanout failure, and notification/outbox recovery.
Run against PostgreSQL and RabbitMQ through Compose, retain reports and ordered
failure timelines, and link each scenario to its contract and task. Depends on
CORE-23, CORE-25, BFF-08, and BFF-09.

## Completion evidence

The public probe sends `X-Acceptance-Fault: rollback` to an explicit
contract-shaped fault fixture. The fixture returns `409 TEST_ROLLBACK`, while
concurrent requests run through a threaded HTTP server and produce one `200`
and one `409`. Authorization, BFF fanout failure, and recovery remain public
HTTP/GraphQL probes. The deterministic suite passes all five journeys; the
Compose-backed `make acceptance-live` run remains environment-dependent.
