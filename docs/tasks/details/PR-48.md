# PR-48: CI dependency vulnerability review gate

- Phase: production_hardening
- Owner role: coordinator
- Dependencies: PR-21, PR-38
- Owned paths: reusable CI workflow, task detail, and progress evidence

## Objective

Add an actual dependency vulnerability review gate to CI. The existing SBOM
baseline checker validates artifact presence and dependency policy but does not
compare introduced dependencies against known advisories.

## Acceptance criteria

- Pull requests run the official GitHub dependency-review action.
- High and critical introduced vulnerabilities fail the gate.
- The gate is read-only and does not weaken existing SBOM or security checks.
- Push/release workflows remain valid when no pull-request base is available.

## Current increment

The reusable CI workflow now runs the official GitHub dependency-review action
for pull requests, failing on introduced high-severity or critical advisories.
The job is skipped for non-PR workflow calls, preserving push/release workflow
validity. The PR and branch callers now propagate the job's least-privilege
`pull-requests: read` permission, preventing reusable-workflow validation errors.
Workflow yamllint and diff checks passed; hosted GitHub validation remains the
final confirmation.
