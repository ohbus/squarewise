# QA-06: Isolate JpaOutboxStoreTest from inter-suite database pollution

## Objective

Fix the test failure in `JpaOutboxStoreTest > persists claim retry acknowledgement and parking state()`, which failed at line 44 (`assertTrue(store.claim(10, Duration.ofMinutes(1)).isEmpty())`) when executed as part of the full `:app:expense-core:test` suite.

## Root Cause

`JpaOutboxStoreTest` tests the outbox claim mechanism against the shared in-memory test database without cleaning up between tests. Prior tests in the suite (specifically `JpaGroupStoreTest` during group rename operations) commit `group.renamed.v1` outbox records to `expense_outbox`. When `JpaOutboxStoreTest` subsequently ran, those unconsumed records remained in `expense_outbox` and were returned by `store.claim(10, ...)`, violating the assertion that the outbox was empty.
