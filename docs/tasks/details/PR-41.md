# PR-41: BFF fail-closed financial fanout

- Phase: production_hardening
- Owner role: coordinator
- Dependencies: PR-06, PR-20
- Owned paths: BFF REST gateway/tests, and this task detail

## Objective

Prevent the BFF from presenting incomplete balances or expenses as a successful
empty group response when an Expense Core fanout request fails.

## Acceptance criteria

- Balance and expense fanout failures propagate to the group response.
- A downstream failure cannot be converted into an empty financial collection.
- Successful group fanout behavior remains supported and tested.

## Validation

- `./gradlew.bat :app:bff:test --rerun-tasks --no-daemon`

## Current increment

Removed the balance and expense `onErrorReturn(emptyList())` fallbacks from the
BFF group fanout. Added regression tests proving HTTP 503/502 failures from
those financial endpoints propagate as upstream errors. The full BFF test suite
passed.
