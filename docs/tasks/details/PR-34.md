- Phase: production_hardening

## Objective

Remove recipient PII and raw exception messages from notification operational
logs while retaining safe correlation and failure classification.

## Acceptance criteria

- Email addresses never appear in notification log message arguments.
- Delivery logs use a deterministic opaque recipient identifier.
- Failure logs use classified error categories rather than exception messages.
- Tests verify the redaction helper and delivery outcomes remain unchanged.

consumer log templates. Focused redaction tests cover stable, non-email output.
