# PR-32: Deployment overlay configuration alignment

- Phase: production_hardening
- Owner role: coordinator
- Dependencies: PR-28, PR-31
- Owned paths: production/staging Compose overlays, deployment operations docs, and this task detail

## Objective

Make the production-like staging overlay supply the configuration names and
profile/capability flags that application fail-closed guards actually consume.

## Acceptance criteria

- Staging uses the BFF property names consumed by the gateway and validator.
- Deployed services activate the production profile explicitly.
- Required service images are supplied explicitly rather than silently using
  mutable defaults.
- Compose rendering fails when required deployment values are absent.

## Validation

- `docker compose -f infra/deploy/docker-compose.prod.yml -f infra/deploy/docker-compose.staging.yml config`
- `git diff --check`

## Current increment

Aligned staging BFF environment names with the gateway's consumed properties,
made infrastructure image references explicit, activated the production
profile through the shared production defaults, and required deployed outbox
capability values at Compose interpolation time.
