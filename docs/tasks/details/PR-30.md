## Objective

Ensure a member removed from a group cannot continue receiving GraphQL
subscription updates until the subscription TTL expires.

## Acceptance criteria

- `member.removed` events revoke the removed subject's active subscriptions for
  the affected group before subsequent updates are published.
- Other members' subscriptions remain active.
- Duplicate removal events remain idempotent through existing event
  deduplication.
- Focused tests prove removed members receive no later group updates.
